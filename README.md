# Tamatem Wiki

Standalone game knowledge and script-writing app extracted from the SuperStar UGC agent.

## Run

```powershell
npm.cmd install
.\run-app.ps1
```

The app runs on:

```text
http://127.0.0.1:8790
```

## Notes

- Add API keys locally in `.env`.
- Runtime brain data, uploaded files, memory entries, and generated outputs are intentionally not committed.
